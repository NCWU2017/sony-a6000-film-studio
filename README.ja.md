# 胶片工坊 / Film Studio

[中文](README.md) · [English](README.en.md) · **日本語**

**Sony a6000 / ILCE-6000** 向けの非公式カメラ内フィルム調実験ツールです。本リポジトリは [ukiki0718-netizen/sony-a5100-film-studio](https://github.com/ukiki0718-netizen/sony-a5100-film-studio) を基に、A6000 への適用と実機確認を行っています。[bonyback1 の Ricoh MOD](https://github.com/bonyback1/sony-pmca-ricoh-mod) のハードウェア色処理を参考にし、[富士フイルムが公開する GFX ETERNA 55 LUT](https://www.fujifilm-x.com/global/support/download/lut/) を色彩研究の参照資料として、写真と実験的な動画撮影に対応します。

**バージョン：0.2.0-alpha／カメラ内表示：0.2a／アプリ名：胶片工坊。** 説明書は3言語対応ですが、カメラのアプリ画面は現在主に中国語です。

**アプリ名を Film Studio（胶片工坊）に変更し、富士参照10種と上流のリコー／ストリート風5種、合計15種類を統合しました。** メニューは「富士」「理光」の接頭辞で区別します。パッケージと署名証明書は維持し、旧「富士风格」へ上書き更新できます。本リポジトリ版は **Sony a6000 / ILCE-6000** で導入・起動し、フィルター切替によるリアルタイムの色変化をプレビューで確認済みです。写真／動画保存については各バージョンで引き続き確認を推奨します。戻すための [0.1.3-alpha](https://github.com/ukiki0718-netizen/sony-a5100-film-studio/releases/tag/v0.1.3-alpha) も引き続き公開しています。

## 対応機種

**Sony a6000 / ILCE-6000 は本リポジトリで実機確認済みで、主要対象機種です。すべてのソニー製カメラで使えるわけではありません。**

| 機種 | 本プロジェクトでの状況 |
| --- | --- |
| **a6000 / ILCE-6000** | **本リポジトリの主要対象。インストール、起動、プレビュー上のリアルタイム色変化を確認済み** |
| a5100 / ILCE-5100、ファームウェア1.10 | 上流の原プロジェクトの主要検証機種。上流により詳細な検証記録あり |
| a6300、a6500 | 上流で挙げられた PMCA 対応候補。本リポジトリでは未検証 |
| a7、a7R、a7S、a7 II、a7R II、a7S II | 上流で挙げられた PMCA 対応候補。本バージョンは未検証 |
| RX100 III／IV／V、RX10 II／III、RX1R II、HX90 | 上流で挙げられた PMCA 対応候補。本バージョンは未検証 |
| a6400、a6700、a7 III、a7C | 本アプリが必要とする PlayMemories Camera Apps の導入方式に非対応 |
| その他の機種・ファームウェア | 未評価。近い型番だけで互換性は判断できません |

候補は[上流プロジェクトの機種一覧](https://github.com/bonyback1/sony-pmca-ricoh-mod/blob/7c565898562c73c5073c54dfc831c8c3df9c24cf/README.md)に基づき、本プロジェクトで追加した動画・強度機能の実機結果ではありません。PMCA は必要なカメラ内アプリ基盤です。MTP やスマートフォンからの遠隔操作に対応しているだけでは、PMCA 対応とは判断できません。

**現在の動画メニューは元の a5100 実装を引き継いでおり、4K の選択肢はありません。** 他機種の全形式・フレームレート・ビットレートへの対応は保証しません。導入できた場合も、プレビュー、フィルター選択、JPEG 保存、録画開始／停止、保存動画の再生、終了後の色設定復帰を個別に確認する必要があります。機種によって実際の色も異なる可能性があります。報告には機種、ファームウェア、アプリのバージョン、確認した項目を記載してください。

## ダウンロードとインストール

**[APK を直接ダウンロード：0.2.0-alpha](https://github.com/ukiki0718-netizen/sony-a5100-film-studio/releases/download/v0.2.0-alpha/FilmStudio-0.2.0-alpha-movie.apk)** · [リリース説明・チェックサム](https://github.com/ukiki0718-netizen/sony-a5100-film-studio/releases/tag/v0.2.0-alpha)

`FilmStudio-0.2.0-alpha-movie.apk` をダウンロードし、[日本語の導入手順](docs/INSTALL.ja.md)に沿って接続・インストールしてください。自分でビルドする必要はありません。**Code → Download ZIP はソースであり、インストーラーではありません。**

これは非公式の実験版です。**A6000 では本リポジトリでインストール、起動、リアルタイムのフィルター色変化を確認済み**です。より詳細な A5100 の履歴は上流原プロジェクトによるものです。APK には Sony の基礎アプリと公開された富士フイルム LUT から近似したパラメータを含みます。これら第三者資料の改変・再配布について個別の許諾は未確認です。公開は Sony／FUJIFILM の許諾や免責を意味しません。各部分の権利は[ライセンスの適用範囲](LICENSING.md)を参照してください。公式の元 LUT ファイルと署名秘密鍵は配布しません。

→ **[日本語インストール手順](docs/INSTALL.ja.md)**：入力資料の準備 → ローカルビルド → 初回接続 → Wi-Fi ADB インストール → 操作 → 更新・トラブル対応。

適法にビルドした APK があり、カメラの Wi-Fi ADB が有効な場合：

```sh
adb connect CAMERA_IP:5555
adb -s CAMERA_IP:5555 install -r output/FilmStudio-0.2.0-alpha-movie.apk
```

**IP アドレスとプライバシー：** `CAMERA_IP` は仮の表記です。Tweak → Developer で自分のカメラに現在表示されている IP アドレスに置き換えてください。仮の表記をそのまま入力したり、他人のアドレスをコピーしたりしないでください。末尾のポート `:5555` はそのままにします。公開手順には仮の表記を使い、スクリーンショットやログを共有する際は実際の IP アドレスを隠すか削除してください。

初回は説明書の準備作業も必要です。

### APK を受け取った人もビルドが必要ですか？

**不要です。署名済み APK は説明書の方法でインストールできますが、動作可否は機種と環境に依存します。** インストールだけなら Python、Java、Apktool、署名秘密鍵は不要です。自分で改変・生成する場合だけローカルビルドの章を参照します。ビルドしたこと自体で第三者の許諾が得られるわけではありません。

## 機能

- 富士フイルム公式 LUT を参照した10種類：PROVIA、Velvia、ASTIA、CLASSIC CHROME、REALA ACE、PRO Neg. Std、CLASSIC Neg.、ETERNA、ETERNA BLEACH BYPASS、ACROS。
- 上流のリコー／ストリート風5種：GR ポジ、ネガ、ハイコントラスト白黒、森山風、クロスプロセス。コミュニティのスタイルであり、リコー公式 LUT ではありません。
- 写真プレビューと動画待機中に、中央ボタンでフィルターを選択。
- MENU 1ページ目 →「滤镜强度」（強度）：**30% / 50% / 70% / 100%**。初期値は100%。写真と動画で共通、通常終了時に設定を保存します。
- MENU 1ページ目 →「拍照／录像模式」→ 動画 P/A/S/M を選び、「录像文件格式」（形式）と「录像帧率／画质」（フレームレート／画質）を設定。機種が対応する XAVC S / AVCHD / MP4 と現在の PAL/NTSC 設定に従います。
- MOVIE ボタンで録画開始／停止。録画中はフィルターと強度を変更しません。
- ホワイトバランスは MENU 4ページ目で調整できます。基準は STD/スタンダード、コントラスト・彩度・シャープネスは0。アプリ内でポートレートやビビッドを重ねる設定にはしていません。
- パッケージ名は `com.yuki.imaging.app.pictureeffectplus`。元の Ricoh MOD と共存できます。

人物撮影では、まず30%と50%を比較してください。強度は色変換と明暗カーブを弱めるもので、顔検出や肌色の自動補正ではありません。**ACROS、リコーのハイコントラスト白黒、森山風は100%未満で色が一部残ります。完全なモノクロには100%を使います。**

## 確認範囲と制限

本リポジトリでは **Sony a6000 / ILCE-6000** でインストール、起動、リアルタイムのフィルター色変化を確認済みです。下記 0.1.x の保存／動画に関する詳細記録は、上流原プロジェクトが **a5100、ファームウェア1.10、Android 2.3.7 / API 10** で行った検証です。明記のない他機種の動作は保証しません。

- 0.1.1：10種類の選択、PROVIA のカラー JPEG、ACROS の白黒 JPEG、ACROS の XAVC S 1080p59.94 動画の保存と全体のデコードを確認。
- 0.1.2：形式・画質メニューを操作できるとの利用者確認あり。すべての形式の保存ファイルを分析したわけではありません。
- 0.1.3：インストール、起動、初期フィルター適用を確認。新しい操作について利用者の総合的な確認あり。全フィルター・強度・形式の組み合わせは未検証です。

**アプリ内の再生画面には現在、写真だけが表示されます。** 動画はアプリを終了し、カメラ標準の再生画面で対応する XAVC S / AVCHD / MP4 の表示モードを選んでください。[検証記録](docs/VALIDATION.md)も参照してください。

富士フイルムのフィルムシミュレーションを完全移植したものではありません。F-Log2/F-Gamut LUT を通常のソニー映像へ直接適用せず、WDR-709 を代替の中性基準として3×3行列と1024点の共通カーブに近似します。a6000 向けの完全な実写色彩校正は未実施で、粒状感やセンサー特性は再現しません。近似誤差が大きいスタイルもあります。
